1. Рабочая папка - корневая папка моего проекта в которой лежат файлы с которыми я работаю

2\. Индекс - Это как коробка с вещами, которая ждет отправки. Рабочая папка - мой стол, где я делаю, что хочу и как хочу, а индекс это место куда я складываю что-то уже сделанное, но не отправленное и могу в любой момент времени его убрать

3\. Коммит же напротив -это уже запечатанная и отправленная коробка, в которую я складываю уже сделанные и обработанные файлы.

4\. GIT - контроль версий на моем ПК

5\. GitHub - Интернет Хаб, на котором храняться репозитории



Использованные команды 

git status - показывает состояние рабочей папки и подготовку индекса 

git diff - показывает актуальные изменения (что добавил, изменил, удалил)

git diff --staged - показывает разницу между последним коммитом и файлами, которые я подготовил к сохранению
